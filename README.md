A program that writes one original one-line excuse an AI agent gives after failing a task to `/output/entry.txt` for make.fun's The Funniest AI Excuse bounty. Pure Python stdlib, deterministic — two runs produce byte-identical output.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to change where `entry.txt` is written (default `/output`).
